# TwitchChatReader (TCR)

Удобное приложение для просмотра Twitch-стримов и чтения чата в одном окне. 
Написано на Python с использованием CustomTkinter.

## ✨ Основные возможности
- Встроенный плеер Twitch.
- Чтение чата с поддержкой смайликов (эмотов).
- Список избранных каналов (Wishlist).
- Автоматическая проверка обновлений прямо из приложения.

## 🚀 Как запустить (для разработчиков)
1. Установите Python 3.9+
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите: `python twitch_chat.py`

## 📦 Скачать готовую версию
Готовые `.exe` файлы для Windows можно скачать в разделе **[Releases](../../releases)**.
